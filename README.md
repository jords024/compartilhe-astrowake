# Compartilhe a Comunidade Astrowake

Página estática (um único `index.html`, sem build e sem servidor). A pessoa sobe a foto, a arte de Stories
(1080×1920) é montada no próprio aparelho, baixa e abre o Instagram.

## Publicar no GitHub Pages
1. Crie um repositório (público) e envie `index.html` e a pasta `assets/`.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O link sai em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Link personalizado no WhatsApp
Para a página receber a pessoa pelo nome (só aparece na página, nunca na arte):

`https://SEU-USUARIO.github.io/NOME-DO-REPO/?nome=Vanessa`

Sem `?nome=`, a página pergunta o primeiro nome ("Qual é o seu nome?").

## O que a página faz
- Foto fica só no aparelho (não é enviada a lugar nenhum).
- Arte: "eu faço parte da COMUNIDADE ASTROWAKE", foto da pessoa, Crassus e `@crassusastrologo`. Dois estilos (escuro e âmbar).
- Textos dentro da área segura dos Stories (250 px livres em cima e embaixo).
- Baixar → aparece "Ir direto para o Instagram" (abre a câmera de Stories; se não abrir, cai no Instagram) + 3 legendas prontas para copiar.
- A marcação do Crassus é pelo adesivo `@` (o Instagram não deixa pré-colocar): a página avisa a pessoa.
- No celular, aparece também "Compartilhar direto" (menu do sistema).

## Trocar a foto do Crassus
Substitua `assets/crassus.jpg` (qualquer proporção; é recortada em círculo).
